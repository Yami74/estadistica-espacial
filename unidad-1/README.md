# Unidad I – Fundamentos de Estadística Espacial

## Temas cubiertos

- Introducción a los datos espaciales
- Tipos de geometría: puntos, líneas, polígonos
- Sistemas de Referencia de Coordenadas (SRC / CRS)
- Autocorrelación espacial – Índice de Moran
- Análisis Exploratorio de Datos Espaciales (AEDE)
- Mapas coropléticos y visualización

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `datos/` | Shapefiles y datasets utilizados |
| `scripts/` | Código R para los análisis |
| `resultados/` | Mapas y gráficas generadas |

## Scripts principales

- `01_intro_sf.R` – Carga y visualización de datos espaciales con `sf`
- `02_autocorrelacion.R` – Cálculo del Índice de Moran con `spdep`
- `03_aede.R` – Análisis exploratorio espacial
